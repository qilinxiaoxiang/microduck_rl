# Small shared contract: what crosses each boundary

This is the proposed v1 software boundary, exercised by `starter/rehearse.py`. It is not a replacement for the robot's existing motor loop. `starter/coordinator.py` emits intentions only; task E maps them into the existing executor and verifies readback.

1. **A → E: call/request/cancel.** Fields: `v`, `kind`, monotonic receive time `t`, `caller_id`; fetch includes `target_type: orange_ball`. The caller reference must resolve to a saved, consented identity/appearance cue on the real system. A tracker ID or speaker direction alone is not persistent identity. A/B jointly bind the caller, and treat ambiguity as unresolved.
2. **B → E/C: selected target and gaze/velocity request.** Track includes `capture_t`, receive `t`, `target_id`, `target_type`, `visible`, confidence meaning, pixel `bbox_xywh`, `image_wh`, source. Image x right/y down; normalized image error is not a joint angle. A receiver must map camera clocks to the shared monotonic clock; it never refreshes an old capture timestamp. The 0.25 s fixture freshness setting is a test parameter, not a calibrated safe limit.
3. **C → D: pickup entry.** Freeze a versioned profile: body/model hash, joint order and units, posture/velocity/head range, last action, actuator/history state, visual history and valid target. D returns its actual supported region after F0; B/C supply an entry sample ID and the readback proving it lies inside that region. `within_entry` in this starter is hand-authored, not a real estimator.
4. **D → C/E: pickup exit.** Preserve physical state and controller history; declare lifted, held, upright and supported exit using validated readback. Same-length 61-value inputs have different meanings in walking and pick policies; use named adapters. Never blend raw action arrays to hide a mismatch. C/E accept loaded motion only inside the agreed exit range.
5. **E → runtime: one active task epoch and motion owner.** Call during walking requests a controlled stop, waits for settled readback, then looks with the head while preserving seated/standing posture. E buffers a fetch request until fresh, correctly bound `caller_looked` readback confirms the head has actually aligned with the caller; settled alone cannot release ball search. Picking has exclusive body control. Cancel requests the skill's supported exit; it is not a mid-bite freeze or abrupt stand command. Manual takeover/emergency revokes the old epoch; old queued results cannot restart autonomy.
6. **Return and handover:** E selects the saved caller; B reacquires that person, C carries, E stops in the measured wait zone and keeps the grip. D supplies payload evidence; E distinguishes verified human take from a drop. E owns conservative stop/help on uncertainty; autonomous retry is added only when its recovery state is validated. A quack/expression must not open a loaded jaw.

## Joint acceptance

B/C → D → C → B/E must run from the previous segment's actual exit, without resetting pose, speed, previous action, visual history or payload. Save all transitions, failed entries, target loss, interventions, empty bites, drops and completion evidence. Single-module success cannot close this test.

A typed record is not proof of the fact it names: the live adapters must show where `settled`, `caller_looked`, `within_entry`, `held`, `supported_exit`, `within_wait_zone` and `take_confirmed` come from. Task E and the producing task own those estimators and a labelled positive/negative recording for each. If the available sensors cannot distinguish take from drop, that transition remains incomplete and requests help; never infer success from an empty jaw alone.

## Local composed check

From `starter/`: `python3 rehearse.py`. It imports the actual interaction parser, consumes a detector readback saved by the included vision runner, and adds labelled physical event fixtures. It checks complete delivery plus loss, wrong identity, empty bite, unsafe exit, cancellation, revoked authority and jaw-preserving expression cases. To compose fresh detector output: `python3 rehearse.py --tracks vision/out/tracks.jsonl`. This emits JSON only and never accesses robot hardware.
